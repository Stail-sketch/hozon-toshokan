文書名 : 統一郎私記 / 日付なし
作成 : 奈瀬 統一郎（年代不明）
区分 : 職員専用アーカイブ / KJ-2021-04
三月十四日のことを、何度も考える。

祖父・奈瀬 昇は三月十四日に死んだ。
父・奈瀬 誠は三月十四日に死んだ。
奈瀬家の当主は、儀式の日付に縛られている。

白奈文香は三月十四日に生まれた。
三月十四日に生まれた人間が、三月十四日に閉じる。

偶然か。
偶然であってほしい。

しかし儀式は偶然を許さない。
俺が死ぬのも三月十四日だろう。
そのとき封印は弱まる。
白奈がこの図書館にいれば、儀式は彼女を選ぶ。

生年月日が同じだということは、
儀式にとって、あの人が最も近い存在だということだ。

俺はそれを知っている。
知っていて、何もしていない。
遠ざけるべきだった。
転勤を勧めるべきだった。
しかし俺はあの人を必要としていた。

儀式のためか。俺自身のためか。
その区別がつかなくなっている。
