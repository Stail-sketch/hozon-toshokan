文書名 : 奈瀬 誠 帳面（第3冊）/ 継承と発見
原本年代 : 昭和7年（1932年）頃
区分 : 奈瀬家文書 / 梶原転記

三代・奈瀬 誠の帳面。誠は顕の長男で、昭和7年に父の死去とともに家督を継承。戦時中を挟む激動の時代の記録。

父が死んだ。昭和七年。

白紙ノ書を受け取った。父の覚書を全て読んだ。儀式記録帳も読んだ。

父が消した人間は74名。

74という数字を見て、私が感じたのは恐怖ではなかった。不足だった。

74名を消してなお、澄奈の支配は完全ではない。外部からの干渉がある。国の制度が変わるたびに、新しい役人が来る。新しい教師が来る。新しい目が増える。父の時代は地方が孤立していたからよかった。しかしこれからは違う。鉄道が来る。通信が来る。この町は外界から隔離されなくなる。

必要悪だ。しかし規模が足りない。

個人で記録を操作するのは限界がある。町の記録だけを消しても、県の記録が残る。国の戸籍が残る。父のやり方では、いずれ矛盾が露呈する。

【梶原メモ】誠の反応は恐怖ではなく計算。74名という数字を「不足」と捉えるこの感覚が、後の政府との協定につながる。誠は父と祖父の限界を正確に見抜いていた。
